# 🖨️ پرینتول (نسخه ۲.۶) | سیستم جامع کافینت و پرینت (PWA)

**پرینتول** یک وب‌اپلیکیشن پیشرفته (Progressive Web App) برای محاسبه سریع هزینه چاپ، پرینت سیاه‌وسفید و رنگی، اسکن، صدور فاکتور رسمی، ثبت آمار مصرف کاغذ و دسترسی سریع به درگاه‌ها و سامانه‌های کاربردی کافی‌نت‌ها است.

## ✨ ویژگی‌های کلیدی نسخه ۲.۶
- **قابلیت نصب (PWA):** نصب مستقیم روی ویندوز، اندروید و iOS از طریق مرورگر (Chrome / Edge / Safari) و اجرای کاملاً آفلاین به کمک Service Worker.
- **صدور و چاپ فاکتور:** درج نام، شماره تماس، آدرس و لوگوی اختصاصی فروشگاه در سربرگ فاکتور.
- **داشبورد آماری:** محاسبه خودکار تعداد برگ‌های مصرفی (A4، A5، A3) و مجموع درآمد به همراه نمودار دایره‌ای.
- **پشتیبان‌گیری و بازیابی (Backup & Restore):** دریافت خروجی JSON از تنظیمات، قیمت‌ها، لوگو و آمار فروش.
- **پیشخوان سایت‌های کافی‌نتی:** دسترسی دسته‌بندی‌شده به ۱۶ گروه از سامانه‌های دولتی، بانکی، دانشگاهی، مالیاتی و ابزارهای کاربردی.

## 📁 ساختار فایل‌های پروژه
```text
printol-pwa/
├── index.html          (فایل اصلی برنامه)
├── manifest.json       (تنظیمات نصب وب‌اپلیکیشن)
├── sw.js               (سرویس ورکر جهت اجرای آفلاین)
├── font.ttf            (فونت فارسی آفلاین)
├── .nojekyll           (تنظیمات انتشار مستقیم در GitHub Pages)
├── icons/              (آیکون‌های استاندارد نصب اپ)
│   ├── icon-192.png
│   └── icon-512.png
└── logo/               (آیکون‌های دسته‌بندی سایت‌ها و خدمات)
    ├── messengers.png
    ├── isp.png
    └── ...
```

## 🚀 راهنمای انتشار رایگان روی GitHub Pages
1. وارد حساب کاربری خود در [GitHub](https://github.com) شوید و یک مخزن (Repository) جدید با نام دلخواه (مثلاً `printol`) به صورت **Public** بسازید.
2. محتویات داخل این پوشه (`index.html`، `manifest.json`، `sw.js`، `font.ttf` و پوشه‌های `icons` و `logo`) را مستقیماً در ریشه مخزن آپلود کنید و روی **Commit changes** بزنید.
3. در مخزن خود به تب **Settings** و سپس از منوی سمت چپ به بخش **Pages** بروید.
4. در قسمت **Build and deployment**، گزینه **Branch** را روی `main` (یا `master`) و پوشه را روی `/ (root)` قرار داده و دکمه **Save** را بزنید.
5. پس از ۱ تا ۲ دقیقه، لینک HTTPS برنامه شما به صورت `https://USERNAME.github.io/printol/` فعال می‌شود و با باز کردن آن در مرورگر، دکمه **نصب برنامه** نمایش داده خواهد شد.
