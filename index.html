تمامی فایل‌های مورد نیاز برای تبدیل برنامه به وب‌اپ قابل نصب (PWA) شامل index.html، manifest.json، sw.js، font.ttf، آیکون‌های استاندارد icons/icon-192.png و icons/icon-512.png و تمامی ۱۸ آیکون پوشه logo/ در فایل فشرده پروژه قرار داده شده‌اند.

گام اول: ساخت مخزن (Repository) در گیت‌هاب

وارد سایت github.com شوید، از بالای صفحه روی علامت + کلیک کرده و گزینه New repository را بزنید. نام مخزن را مثلاً printol بگذارید، وضعیت آن را روی Public قرار دهید و روی Create repository کلیک کنید.

گام دوم: آپلود فایل‌های داخل پکیج ZIP

فایل ZIP پروژه را از حالت فشرده خارج (Extract) کنید. در صفحه مخزن گیت‌هاب روی لینک uploading an existing file کلیک کنید، تمام فایل‌ها و پوشه‌های داخل پکیج (index.html، manifest.json، sw.js، font.ttf، icons و logo) را با هم بکشید و رها کنید (Drag & Drop) و در پایین صفحه دکمه سبز Commit changes را بزنید.

گام سوم: فعال‌سازی GitHub Pages (لینک HTTPS)

در بالای صفحه مخزن وارد تب Settings شوید و از منوی سمت چپ گزینه Pages را انتخاب کنید. در بخش Branch گزینه None را به main تغییر دهید، پوشه را روی / (root) بگذارید و روی Save کلیک کنید.

گام چهارم: نصب برنامه روی دسکتاپ و موبایل

پس از حدود ۱ دقیقه صفحه را رفرش کنید تا آدرس آنلاین شما (به شکل https://username.github.io/printol/) نمایش داده شود. با باز کردن این لینک در مرورگر Chrome یا Edge، بنر «نصب پرینتول روی دستگاه» ظاهر می‌شود و برنامه مستقیماً در منوی Start ویندوز یا صفحه اصلی موبایل نصب خواهد شد.
